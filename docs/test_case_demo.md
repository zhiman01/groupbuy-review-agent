## 真实诊断输出

### Workflow 诊断结果（确定性输出）

```
【运营内部分析】
1. 辣子川香（火锅）北京望京店：
   - **核心指标表现**：
     - 点击率（CTR）：本店 8.5%，低于同品类平均 9.5%，说明团购商品对曝光用户吸引力弱于同行；
     - 转化率（CVR）：本店 10.5%，低于同品类平均 12%，点击用户到下单的转化环节存在流失；
     - 核销率：67 核销量/89 下单量 = **75.3%**，处于火锅团购常规区间（70%-80%），整体核销表现合格；
   - **核心问题**：流量转化前端（曝光→点击→下单）双环节均低于品类均值，流量获取后的转化效率不足，未充分挖掘曝光流量价值；
   - **根因诊断**：
     1. 点击率偏低：可能存在主图吸引力不足、套餐展示不清晰、价格锚点突出不够等问题，导致曝光用户点击意愿低于同行；
     2. 转化率偏低：套餐详情页用户评价数量少（仅 23 条），信任背书不足，同时套餐性价比没有匹配用户预期，影响下单决策。
   - **关键建议**：
     1. 优化点击率：更换团购主图，突出"168 元双人餐含锅底小料"的价格优势，搭配鲜活食材/沸腾锅底的场景化实拍；对比周边同类型双人套餐，检查定价是否具备竞争力，可在主图标注"5.6 折特惠"强化感知。
     2. 提升转化率：引导已核销用户发评价晒单，可配合"评价返 5 元门店抵扣券"活动，快速积累评价提升信任；在套餐详情补充菜品分量、规格说明，减少用户决策顾虑。
     3. 核销维护：当前核销率合格，可继续保持到店提醒，进一步降低未核销率。

【可转发给商家的沟通话术】

**致辣子川香（北京望京店）：**
您好，我们帮您复盘了上周（12.1-12.7）双人套餐的团购经营数据，给您整理了一些优化建议：
1.  从数据来看，您的团购曝光后点击转化率和下单转化率暂时都略低于望京商圈同品类火锅门店的平均水平，我们建议您可以先优化一下团购商品的主图，把"168 元双人餐含 4 荤 5 素 + 锅底小料（原价 299 元）"的优惠信息更突出展示，搭配新鲜食材的实拍图，更能吸引用户点击。
2. 目前您的套餐评价数量还比较少，用户下单前的参考不足，您可以引导到店核销的用户晒单评价，比如做一个"评价满图返 5 元下次到店抵扣券"的小活动，积累评价后能有效帮助新用户决策，提升下单转化。
3. 当前您的套餐核销率在 75% 左右，属于行业正常水平，可以继续保持核销提醒，进一步提升到店率哦。

如果您近期调整过套餐主图/价格，或者对数据有疑问，我们可以再帮您进一步分析~
（以上建议仅供参考，具体调整可结合门店实际情况确认后落地）
```

## Agent 追问演示

### 场景 1：商家问"封面图怎么改？"

**用户输入：** "封面图怎么改？"

**Agent 回复：**

> 1️ **突出核心单品**
>    咱们的双人套餐，用户最关心的是毛肚和肥牛。建议：
>    - 毛肚占画面 60%，特写七上八下的脆感
>    - 肥牛纹理清晰，带点红油的光泽
>    - 锅底在底部露出，红油的层次感
>
> 2️⃣ **增加食欲元素**
>    - 锅底冒出的热气（后期加一点烟雾效果）
>    - 撒上的葱花/香菜点缀
>    - 右下角放一双筷子夹肉的动作
>
> 3️⃣ **文案标签**
>    - 左上角：「望京火锅 TOP3」（如果属实）
>    - 右上角：「限时 5.6 折」（醒目字体）
>    - 底部小字：「可叠加会员价」
>
> 参考同商圈表现优秀的几家店，他们的封面图都有"核心单品特写 + 热气感 + 折扣标签"这三个元素。

### 场景 2：运营问"这个诊断的置信度如何？"

**用户输入：** "转化率诊断的置信度如何？"

**Agent 回复：**

> 转化率诊断的置信度：中等偏高（75%）
>
> **诊断依据：**
> ✓ 点击到下单转化率 10.5%，低于同品类 12%（显著差异）
> ✓ 点击到核销转化率 75%，低于品类平均 85%
> ✓ 商家详情页缺少真人内容（探店视频/达人打卡）
> ✓ 近期 2 条差评未回复（影响决策）
>
> **不确定性因素：**
> ⚠️ 未获得商家真实的"加购未下单"数据
> ⚠️ 竞品近期是否有促销活动暂不明确
> ⚠️ 周一到周日是否有特殊事件（如暴雪）影响
>
> **建议：**
> 1. 查看商家后台"加购未下单"漏斗数据，确认用户在哪个环节流失
> 2. 问商家最近一周是否有异常事件
> 3. 观察同商圈竞品近期动作

## 面试演示话术

### 开场（30 秒）

> "抖音生活服务有 1500 万家动销门店，运营每周要批量复盘几十家商家的团购数据。我做的这套系统定位是 AI 中台能力，先服务内部运营：AI 出诊断→运营二次校验→再同步给商家。"

### 架构选型（1 分钟）

> "架构上我用了 Agent + Workflow 双层。选型逻辑是看路径是否确定：批量周报用 Workflow，稳定可控；深度追问用 Agent，路径开放。这个判断我在之前推荐链路诊断的 Agent 里也用过。"

### 核心能力（1 分钟）

> "有两个设计我比较满意：第一是双输出结构——内部分析用专业术语，商家话术用友好语气，运营不用自己改写。第二是合规护栏——AI 不能越权替商家做决策，我迭代过三版。"

### 合规护栏迭代（1 分钟）

> "V1 用固定词表拦，但模型换个说法就漏过去了。V2 把词库下沉到强制信号词，大部分越权被拦住了。V3 设计了 LLM 语义审查节点，V2 做前置快拦，V3 做后置精审，双层互补。"

### 评测体系（1 分钟）

> "评测我分了 Workflow 和 Agent 两套，数据集不是随机采样，是按失败模式反向构造对抗集。有个细节：意向分层我倾向看混淆矩阵而不是单一准确率，因为不同方向的错代价不对称。"

### 主动讲局限（30 秒）

> "我也清楚这套评测的边界：数据是我按失败模式构造的，样本量有限、单人标注，所以它是压力测试，能暴露问题，但给不出置信的线上准确率。"

### 收尾（30 秒）

> "总结一下，这个项目从需求拆解、架构选型、Prompt 设计、评测体系到迭代闭环，整套方法论是我真实走过一遍的。如果入职，我第一步会跟运营做 1v1 访谈验证痛点，然后优先选一个高频场景做 MVP。"

## 临场应变话术

### 如果面试官说"这个很简单嘛"

> "确实，单个 case 的解决方案不复杂。但这个项目真正的价值在于：我们把它做成了一个可复用的 AI 中台能力，可以覆盖到 400+ 城市的 1500 万 + 门店。而且我们考虑了合规、评测、运营协作这些非技术问题，这些才是落地的关键。"

### 如果面试官问"为什么不用 GPT-4"

> "我们在测试中发现，对于本地生活这种垂直领域，字节自研的 doubao 在理解本地场景（如"望京火锅"、"排队久"这类表述）方面更有优势。而且从成本和部署角度看，doubao 也更符合业务需求。"

### 如果面试官问"你最大的困难是什么"

> "最大的困难是平衡'诊断准确性'和'商家体验'。比如有些商家的问题很敏感（如服务态度差），直接说出来可能引起抵触。我们花了很多时间设计双输出机制，内部报告要直言不讳，商家话术要委婉建设。这个细节是我之前没意识到的，和运营同事聊了很多次才想清楚。"
