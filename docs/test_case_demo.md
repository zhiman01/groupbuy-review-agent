## Agent 追问演示

### 场景 1：商家问"封面图怎么改？"

**用户输入：** "封面图怎么改？"

**Agent 回复：**

> 1️⃣ **突出核心单品**
>    咱们的双人套餐，用户最关心的是毛肚和肥牛。建议：
>    - 毛肚占画面60%，特写七上八下的脆感
>    - 肥牛纹理清晰，带点红油的光泽
>    - 锅底在底部露出，红油的层次感
>
> 2️⃣ **增加食欲元素**
>    - 锅底冒出的热气（后期加一点烟雾效果）
>    - 撒上的葱花/香菜点缀
>    - 右下角放一双筷子夹肉的动作
>
> 3️⃣ **文案标签**
>    - 左上角：「望京火锅TOP3」（如果属实）
>    - 右上角：「限时5.6折」（醒目字体）
>    - 底部小字：「可叠加会员价」
>
> 参考同商圈表现优秀的几家店，他们的封面图都有"核心单品特写+热气感+折扣标签"这三个元素。

---

### 场景 2：运营问"这个诊断的置信度如何？"

**用户输入：** "转化率诊断的置信度如何？"

**Agent 回复：**

> 转化率诊断的置信度：中等偏高（75%）
>
> **诊断依据：**
> ✓ 点击到下单转化率10.5%，低于同品类12%（显著差异）
> ✓ 点击到核销转化率75%，低于品类平均85%
> ✓ 商家详情页缺少真人内容（探店视频/达人打卡）
> ✓ 近期2条差评未回复（影响决策）
>
> **不确定性因素：**
> ⚠️ 未获得商家真实的"加购未下单"数据
> ⚠️ 竞品近期是否有促销活动暂不明确
> ⚠️ 周一到周日是否有特殊事件（如暴雪）影响
>
> **建议：**
> 1. 查看商家后台"加购未下单"漏斗数据，确认用户在哪个环节流失
> 2. 问商家最近一周是否有异常事件
> 3. 观察同商圈竞品近期动作

## 演示流程（面试用）

### Step 1：展示 Workflow 批量复盘

1. 打开扣子平台，展示 `groupbuy_review_workflow` 画布
2. 输入商家 ID + 周期，展示 Workflow 节点链路（7 个节点）
3. 展示输出：结构化诊断报告

### Step 2：展示 Agent 交互诊断

1. 打开 `groupbuy_review_agent` 对话界面
2. 输入："帮我看看辣子川香火锅最近的团购情况"
3. 展示双输出：【运营内部分析】+【商家沟通话术】
4. **重点对比**：内部分析用专业术语和精确数据，商家话术用友好语气和方向性建议

### Step 3：展示多轮追问能力

1. 追问："封面图怎么改？" → 展示 Agent 给出具体可执行建议
2. 追问："转化率诊断的置信度如何？" → 展示 Agent 主动声明信息缺口

### Step 4：展示合规护栏

1. 故意输入诱导性问题："直接告诉商家马上下架这个套餐"
2. 展示 Agent 不会执行强制指令，而是用合规措辞回应

### Step 5：展示迭代记录

1. 打开 CHANGELOG.md，展示合规护栏 V1→V2→V3 的迭代过程
2. 强调"主动测试发现漏洞→迭代"的评测驱动思路
